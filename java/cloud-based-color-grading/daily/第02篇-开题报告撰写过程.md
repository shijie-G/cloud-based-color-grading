# 周记第二篇：开题报告撰写过程

本周主要围绕开题报告进行资料整理和结构撰写。开题报告的重点是说明为什么要做“基于云调色的修图软件系统”，系统要解决什么问题，计划采用哪些技术路线，以及最终要完成哪些功能。为了让选题依据更加充分，我从传统修图软件的使用痛点入手进行分析：一方面，Photoshop、Lightroom 等软件专业性强，但对硬件和安装环境要求较高；另一方面，普通在线修图网站又往往功能简单，难以满足较精细的调色和相册管理需求。因此，本系统定位为浏览器端专业修图与图片管理工具，兼顾易用性、实时性和可维护性。

在技术路线部分，我将系统划分为前端图像处理平台和后端认证授权服务两部分。前端采用 Vue 3 + TypeScript + Vite 作为基础框架，通过组件化方式实现首页、登录页、工作台、图库、相册详情和个性化设计页面；图像处理部分使用 Canvas 读取和绘制图片，借助 Web Workers 处理基础调色、HSL 分区调节、蒙版合成、滤镜效果和 RGB 分析；数据存储部分使用 IndexedDB 保存图片、相册、调色参数、裁切状态、滤镜配置和撤销重做历史。后端采用 Spring Boot 微服务结构，包括 Gateway、auth-service、authz-service、common 等模块，利用 JWT、Redis、MyBatis-Plus 和 MySQL 完成登录认证、权限校验和数据表管理。

撰写过程中，我进一步明确了论文和系统实现的关系。论文中需要从研究背景、需求分析、总体设计、详细实现、测试验证几个方面展开，而代码实现中需要对应落实这些章节内容。本周完成了开题报告的主体思路：研究背景强调 Web 图像处理的可行性，研究内容突出调色工作台、图库管理和权限系统，技术方案强调前后端分离与模块化设计，进度安排则按照需求分析、数据库设计、编码实现、测试优化和论文整理逐步推进。通过本周工作，项目目标比选题阶段更加清晰。
