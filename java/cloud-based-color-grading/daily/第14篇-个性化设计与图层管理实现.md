# 周记第十四篇：个性化设计与图层管理实现

本周主要研究个性化设计模块。该模块位于 src/views/personalize，功能是在已调色图片的基础上继续添加文字、形状、贴纸或其他图片图层，形成更具创意的最终作品。PersonalizePage 作为主页面，包含素材面板、画布区域、属性面板、图层面板和图片选择器。用户可以从图库中选择一张图片作为底图，系统会读取该图片的调色参数、HSL 参数、蒙版和滤镜配置，并通过 useHSLState 重新生成调色后的 baseImageUrl，确保个性化设计建立在最终调色结果之上。

图层管理由 useLayerManager 实现。每个图层包含 id、name、type、visible、locked、opacity、x、y、width、height、rotation、zIndex 等属性，图片图层还包含 imageUrl，文字图层包含文本、字体、颜色等配置。该组合式函数提供 addLayer、removeLayer、updateLayer、selectLayer、moveLayerUp、moveLayerDown、toggleLayerVisibility、toggleLayerLock、duplicateLayer、clearLayers 和 reorderLayers 等方法。图层按 zIndex 排序后在 CanvasArea 中绘制，用户可以通过图层面板调整层级，通过属性面板修改位置、大小、旋转、透明度等参数。

为了保证编辑结果可以恢复，usePersonalizeStorage 负责将图层数据序列化后保存到 IndexedDB 的 personalizeLayersJson 字段。保存时会把坐标和尺寸按画布宽高转换为比例，加载时再根据当前图片尺寸还原，这样可以减少不同尺寸显示带来的偏差。图层变化使用 watch 监听，并通过 500ms 防抖自动保存。本周通过分析个性化模块，我认识到图层系统是图片处理之外的另一类复杂状态管理，需要同时考虑绘制顺序、交互选中、属性编辑、持久化和恢复。
