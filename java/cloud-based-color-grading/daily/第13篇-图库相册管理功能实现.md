# 周记第十三篇：图库相册管理功能实现

本周主要研究图库和相册管理功能。图库模块位于 src/views/gallery，目标是提供类似 Lightroom 的图片管理体验。GalleryPage 作为主页面，内部组合 AlbumList、AlbumCard、ImageBrowser、ThumbnailStrip、ImageViewer、QuickFilterBar 和 BatchActionBar 等组件。用户可以创建相册、进入相册详情、查看缩略图、选择图片、收藏图片、删除图片以及进行批量操作。相册按创建时间和月份分组，方便用户按照拍摄或整理时间查找图片。

数据层面，图库功能复用了工作台的 IndexedDB 存储能力。useGalleryDB 提供相册和图片的读写接口，并在 ImageRecord 与 ImageDBItem 之间进行转换。useAlbumState 负责相册列表、当前相册和月份分组；useImageState 负责当前相册中的图片列表、当前图片、排序方式和快速筛选；useSelection 负责多选状态，支持 Ctrl/Cmd 点击、Shift 范围选择、全选和清空选择。批量操作栏可以根据 selectedIds 对多张图片执行收藏、删除或移动等操作。

界面交互方面，ImageViewer 支持大图查看、滚轮缩放、双击重置、拖拽平移和旋转；ThumbnailStrip 用于快速切换图片；QuickFilterBar 提供全部、仅收藏、最新上传等筛选模式。图片删除采用 isDeleted 标记，为后续回收站功能保留扩展空间。通过本周分析，我认识到图库模块不仅是图片列表展示，更承担了图片资产管理的职责。它与工作台相互配合：图库负责组织图片，工作台负责精修处理，两者共同构成完整的修图工作流程。
