# 周记第三篇：系统功能分析

本周主要进行系统功能分析。根据项目定位，系统面向需要在线管理和处理图片的用户，核心功能可以分为用户认证、图片工作台、图库相册、个性化设计、图片导出和系统权限管理几大部分。首先是用户认证功能，用户通过登录页输入账号和密码，前端调用认证接口，后端验证成功后返回 JWT Token、用户信息、角色和权限信息，前端再将 Token 保存到 Pinia 状态和本地存储中，并在后续请求中自动携带 Authorization 请求头。

图片工作台是系统的核心模块。用户可以上传图片，系统生成缩略图并保存到 IndexedDB。进入工作台后，左侧显示图片预览和底部图库，右侧提供调色面板。基础调色包含亮度、对比度、高光、阴影、白色、黑色、饱和度、自然饱和度、色相、色温、色调、清晰度和去朦胧等参数；HSL 调色支持对红、橙、黄、绿、青、蓝、紫等颜色范围分别调整色相、饱和度和明度；滤镜功能提供胶片、复古、青橙、冷调等风格化处理；裁切功能支持比例选择、旋转和翻转；蒙版功能支持线性渐变和径向渐变，实现局部调色。

图库相册模块主要负责图片组织管理，包括创建相册、按月份分组、批量上传、查看缩略图、收藏、删除、快速筛选和多选批量操作。个性化设计模块在调色结果基础上增加图层能力，可以添加文字、形状、贴纸和图片图层，并调整位置、大小、旋转、透明度、层级和锁定状态。导出模块则负责将最终结果保存为 JPEG、PNG 或 WebP，并支持质量、DPI、水印和图层合并等配置。通过本周分析，我明确了系统各模块的职责边界，为后续数据分析和总体设计打下基础。
