# 周记第十一篇：蒙版局部调色功能实现

本周主要研究蒙版局部调色功能。相比全局调色，蒙版可以让用户只调整图片中的一部分区域，例如只压暗天空、提亮人物面部或增强画面边缘氛围。项目中 useMaskState 负责蒙版状态管理，支持 linear 线性蒙版和 radial 径向蒙版两种类型。每个蒙版图层都包含 id、名称、类型、启用状态、反选状态、参数、调整值和 canvas 等信息，用户可以添加多个蒙版图层，并分别设置局部调色参数。

线性蒙版由 drawLinearMask 绘制，代码根据起点、终点和羽化范围创建 Canvas 线性渐变，从而形成由强到弱的过渡效果。径向蒙版由 drawRadialMask 绘制，支持中心点、半径、羽化和旋转角度，适合处理人物、主体或局部光效。生成蒙版后，系统会将各图层合成为 compositeCanvas，并在图像处理链中把蒙版透明度作为权重参与调色。maskWorker.ts 负责根据蒙版数据和局部调整参数合成最终像素结果。

界面层面，MaskAdjustPanel、MaskControls、MaskCanvas 等组件提供图层选择、显示遮罩、启用禁用、反选、清除和参数调整等操作。用户拖动蒙版或调整局部参数时，系统需要同步更新蒙版图层、重新生成预览并写入历史记录。该功能的难点在于状态较多：既要保存每个蒙版的几何参数，又要保存每个蒙版的调色参数，还要处理多图层叠加和反选逻辑。本周工作让我认识到，蒙版功能是系统从普通滤镜工具向专业修图工具提升的重要标志。
