# 周记第六篇：登录认证功能设计与实现

本周主要研究和实现用户登录认证功能。登录功能是系统安全访问的入口，也是工作台、图库等受保护页面能够正常使用的前提。前端登录页基于 Vue 3 和 Element Plus 编写，表单由 useLoginForm 组合式函数管理，包含账号、密码、表单校验、加载状态、错误提示和登录成功后的跳转逻辑。账号校验支持手机号或邮箱格式，密码不能为空，用户点击登录后先进行表单验证，再调用 userStore.login 方法，由 authApi.ts 向后端 /auth/login 接口发送请求。

前端状态管理使用 Pinia 的 userStore。登录成功后，系统将后端返回的 token、userId、username、nickname、roles、permissions、menus 保存到状态中，其中 token 和部分用户信息写入 localStorage，保证页面刷新后可以恢复登录状态。Axios 请求拦截器会自动读取 userStore 中的 token，并添加 Authorization: Bearer token 请求头，同时附加 X-User-Id，便于后端识别当前用户。响应拦截器负责处理 401 状态，当 Token 无效或过期时清除用户信息并重定向到登录页。

后端认证功能由 auth-service 实现。AuthController 提供 /auth/login、/auth/logout、/auth/refresh 三个接口。AuthServiceImpl 的登录流程包括检查账户是否锁定、查询用户、检查用户状态、使用 BCrypt 验证密码、清除失败记录、生成 JWT、保存 Token 到 Redis、更新最后登录时间、记录安全审计日志并返回登录响应。RedisService 还实现了登录失败计数和账户锁定，连续失败达到阈值后会临时锁定账户。本周通过阅读和梳理该模块，我认识到登录功能不仅是简单的账号密码校验，还需要考虑 Token 生命周期、失败保护、状态恢复和异常提示。
