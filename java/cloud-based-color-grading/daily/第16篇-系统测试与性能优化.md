# 周记第十六篇：系统测试与性能优化

本周主要进行系统测试与性能优化分析。后端项目中已经包含较完整的测试结构，auth-service、authz-service、gateway 和 common 模块下都有 JUnit 测试与属性测试。认证服务测试覆盖登录、用户管理、密码加密、Token 过期、登录失败计数和登出等场景；网关测试覆盖有效 Token 放行、无效 Token 返回 401、白名单路径跳过认证、缺少 Authorization 头返回 401、Token 自动刷新等逻辑；授权服务测试覆盖权限传递性、角色权限修改、菜单树结构和权限缓存一致性。属性测试使用 jqwik 多次生成随机输入，有助于发现边界问题。

前端方面，测试重点主要放在用户流程和图像处理稳定性上。需要验证登录成功后能进入工作台，未登录访问受保护页面会跳转登录页；图片上传后能在 IndexedDB 中保存并在刷新后恢复；调节基础参数、HSL、滤镜、蒙版后预览能够正确变化；裁切、旋转、翻转后可以保存和恢复；相册创建、图片收藏、删除和筛选能够正确更新界面；导出图片时格式、质量、水印和 DPI 设置能够生效。对于图像处理模块，还要关注大尺寸图片、多张图片和频繁拖动滑块时的响应速度。

性能优化方面，系统已经采用多项措施。调色处理使用 Web Workers，避免阻塞主线程；useHSLState 中区分低分辨率预览和高清处理，先快速响应用户操作，再延迟生成高质量结果；图片上传时生成缩略图，减少列表渲染压力；历史记录采用 base + diff 思路并限制最大数量，避免无限增长；IndexedDB 适合存储大图片和 JSON 参数。通过本周测试与优化分析，我认识到毕业设计中的测试不仅要验证功能是否可用，还要验证安全性、稳定性、性能和异常处理是否满足实际使用要求。
