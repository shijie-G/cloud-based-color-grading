# 周记第一篇：选题

本周主要完成毕业设计选题的确定。结合自己平时对摄影、图片后期处理和 Web 应用开发的兴趣，我最终将题目确定为《基于云调色的修图软件系统的设计与实现》。最初考虑过普通图片管理系统、在线相册系统等方向，但这些题目功能较单一，难以体现图像处理、前端交互和后端权限管理的综合能力。经过对现有修图软件的体验和分析，我发现传统桌面修图工具虽然功能强大，但存在安装成本高、设备依赖明显、操作门槛较高、编辑数据不便迁移等问题。因此，我希望设计一个运行在浏览器中的修图系统，使用户可以通过网页完成图片上传、基础调色、HSL 调整、滤镜处理、相册管理和个性化编辑等操作。

在选题阶段，我初步查阅了 Vue 3、TypeScript、Canvas、Web Workers、IndexedDB、Spring Boot、JWT、Redis 等技术资料。前端部分适合承担图像处理与交互展示任务，尤其是 Canvas 可以直接操作像素数据，Web Workers 可以将耗时计算放到后台线程，减少页面卡顿；IndexedDB 能够存储图片数据、缩略图、调色参数和历史记录，满足本地持久化需要。后端部分则采用 Spring Boot 微服务结构，负责用户登录、权限控制和安全审计，保证系统具备基本的账户体系和访问控制能力。

本周还对项目可行性进行了初步判断。系统的核心难点不只在于页面展示，更在于如何保证调色实时性、如何保存非破坏性编辑数据、如何组织多模块代码，以及如何在前后端分离架构下实现安全访问。通过分析现有代码和资料，我认为该选题既具有实际应用价值，也能够覆盖毕业设计要求中的需求分析、系统设计、数据库设计、功能实现和系统测试等环节。后续将围绕该题目继续推进开题报告和系统需求分析工作。
