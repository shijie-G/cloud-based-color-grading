# 周记第九篇：基础调色与 HSL 处理实现

本周主要研究基础调色和 HSL 处理链。基础调色是修图系统最核心的功能之一，用户通过右侧调色面板调整亮度、对比度、高光、阴影、白色、黑色、饱和度、自然饱和度、色相、色温、色调、清晰度和去朦胧等参数后，系统需要实时生成预览结果。useAdjustmentState 负责保存基础调色参数，并根据参数生成 CSS filter 形式的简单预览；更完整的像素级处理则交给 useHSLState 统一调度。

为了避免大图处理阻塞页面，系统使用 Web Workers 处理耗时任务。basicWorker.ts 负责基础调色计算，它会遍历 ImageData 的像素数组，对 RGB 值进行亮度、对比度、饱和度、色温等调整，并通过 clamp 保证颜色值在 0 到 255 范围内。HSL 调整由 hslWorker.ts 完成，Worker 会将 RGB 转换为 HSL，根据颜色所在范围计算权重，再分别调整对应颜色区间的 hue、saturation 和 lightness。红、橙、黄、绿、青、蓝、紫等颜色范围可以独立调整，这使系统具备类似专业修图软件的精细颜色控制能力。

useHSLState 中设计了预览图和高清图两级处理机制。预览阶段会将图片缩放到较小尺寸，快速响应用户拖动滑块；用户停止操作后，再延迟触发高清处理，保证最终结果质量。代码中还根据硬件线程数创建多个 Worker，将图片分块并行处理，最后再合并结果。通过本周学习，我认识到实时调色的关键不只是算法本身，还包括任务调度、降采样预览、并行计算和结果合并。该模块很好地体现了 Web 技术在图像处理场景中的应用价值。
