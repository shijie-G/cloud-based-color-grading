# 周记第十五篇：图片导出与工程文件实现

本周主要研究图片导出和工程文件功能。图片处理完成后，用户需要将作品保存到本地，因此导出模块是系统闭环的重要环节。相册详情中的 useImageExport 提供导出逻辑，支持 JPEG、PNG、WebP 等格式，并可以设置质量、DPI、水印和个性化图层合并。导出时系统先加载原图或处理后的图片，再创建 Canvas 绘制最终画面，若存在水印配置，则根据位置、透明度、字体或图片水印设置进行叠加，最后通过 canvas.toBlob 生成文件并触发下载。

DPI 设置是导出模块中较细节的功能。对于 JPEG，系统会查找 JFIF APP0 标记并修改密度单位与 X/Y 密度；对于 PNG，系统会处理 pHYs chunk，将 dpi 转换为每米像素数写入文件。虽然浏览器导出图片通常不关注 DPI，但在打印、设计交付等场景中该参数仍有意义。导出模块还需要处理图片加载失败、格式不支持、Blob 生成失败等异常情况，保证用户可以得到明确提示。

工程文件功能由 src/utils/gsj 目录实现。gsjExporter 可以将相册、图片、历史记录和编辑参数打包为 GSJ 工程；gsjImporter 可以解析并恢复工程；gsjCrypto 提供加密和解密能力，使用 AES-GCM、AES-CBC、PBKDF2 等机制保护工程内容。工程文件中包含版本、元信息、相册、图片、历史栈和编辑数据，便于用户备份或迁移项目。本周通过分析导出和工程文件，我认识到一个完整的修图系统不仅要能编辑图片，还要能可靠地输出成果、保存工程和恢复工作进度。
