# Workstation 数据存储说明

> 本文档列出所有运行时内存数据和持久化存储数据的字段、类型、作用及生命周期。

---

## 一、内存数据（运行时，刷新后丢失）

### 1. 布局状态（useLayoutState）

| 字段 | 类型 | 默认值 | 作用 |
|------|------|--------|------|
| `leftPanelWidth` | `Ref<number>` | 80 | 左侧图片区宽度（%），范围 70~85 |
| `rightPanelWidth` | `ComputedRef<number>` | 20 | 右侧调色区宽度（100 - leftPanelWidth） |
| `galleryHeight` | `Ref<number>` | 20 | 底部图片全览区高度（vh），范围 16~35 |
| `isResizing` | `Ref<boolean>` | false | 左右分割线是否正在拖拽 |
| `isGalleryResizing` | `Ref<boolean>` | false | 全览区分割线是否正在拖拽 |

---

### 2. 图片状态（useImageState）

| 字段 | 类型 | 默认值 | 作用 |
|------|------|--------|------|
| `imageSrc` | `Ref<string>` | `''` | 当前预览区显示的图片 dataUrl。裁切模式下会被临时替换为变换预览图，取消时恢复 |
| `uploadedImages` | `Ref<ImageItem[]>` | `[]` | 所有已上传图片的元数据列表，底部全览区渲染数据源 |
| `selectedImageId` | `Ref<number\|null>` | `null` | 当前选中图片的 ID |
| `isLoadingFromDB` | `Ref<boolean>` | false | 页面初始化时从 IndexedDB 恢复图片期间为 true |

**ImageItem 结构：**

| 字段 | 类型 | 作用 |
|------|------|------|
| `id` | `number` | 唯一标识（Date.now() + random） |
| `name` | `string` | 文件名 |
| `src` | `string` | 当前展示用 dataUrl（有裁切则为 editedSrc，否则为原图） |
| `originalSrc` | `string` | 原始图片 dataUrl，永不覆盖，用于裁切模式重建变换预览 |
| `thumbnail` | `string` | 200px 缩略图 dataUrl，全览区展示用 |
| `originalFile` | `File` | 原始 File 对象，写入 IndexedDB 的 blob 来源 |
| `fileHash` | `string` | `name_size_type` 拼接的去重哈希 |

---

### 3. 基础调色参数（useAdjustmentState）

| 字段 | 类型 | 默认值 | 作用 |
|------|------|--------|------|
| `adjustments` | `reactive<AdjustmentValues>` | 全部 0 | 7 个基础调色参数，滑块直接绑定，变化时触发 Worker 处理链和防抖保存 |
| `imageFilter` | `ComputedRef<string>` | — | 由 adjustments 计算出的 CSS filter 字符串（兼容旧版，现已被 Worker 像素处理替代） |

**AdjustmentValues 字段：**

| 参数 | 范围 | 作用 |
|------|------|------|
| `brightness` | -150 ~ +150 | 亮度 |
| `contrast` | -100 ~ +100 | 对比度 |
| `saturation` | -100 ~ +100 | 饱和度 |
| `vibrance` | -100 ~ +100 | 自然饱和度（对已饱和颜色影响更小） |
| `hue` | -180 ~ +180 | 色相旋转（度） |
| `temperature` | -100 ~ +100 | 色温（负=冷蓝，正=暖橙） |
| `clarity` | -100 ~ +100 | 清晰度（中间调对比度） |

---

### 4. HSL 颜色范围参数 + 处理链（useHSLState）

| 字段 | 类型 | 默认值 | 作用 |
|------|------|--------|------|
| `hslAdjustments` | `reactive<HSLAdjustments>` | 全部 0 | 7 个颜色范围（红/橙/黄/绿/青/蓝/紫）各自的 H/S/L 偏移，滑块绑定 |
| `processedSrc` | `Ref<string>` | `''` | Worker 处理链输出的 dataUrl，预览区优先显示此值；空字符串时显示原图 |
| `isProcessing` | `Ref<boolean>` | false | Worker 是否正在处理中 |

**内部非响应式变量（模块私有）：**

| 变量 | 作用 |
|------|------|
| `basicAdj` | 当前基础调色参数快照，由 setBasicAdjustments 注入 |
| `currentMaskLayers` | 当前蒙版层列表快照（含 canvas 引用），由 setMaskLayers 注入 |
| `previewData` | 图片的预览版 ImageData（长边 ≤1200px），拖滑块时用于快速响应 |
| `fullData` | 图片的原图尺寸 ImageData，500ms 后高清处理和导出用 |
| `cachedSrc` | 当前缓存对应的 src，src 不变时复用 previewData/fullData |
| `poolBusy` | Worker 池是否忙碌，忙时新请求存入 pendingReq |
| `pendingReq` | 待处理的最新请求（跳帧机制，只保留最新） |

---

### 5. 蒙版状态（useMaskState）

| 字段 | 类型 | 默认值 | 作用 |
|------|------|--------|------|
| `layers` | `reactive<MaskLayer[]>` | `[]` | 蒙版层列表，每层含形状参数、独立调色参数、离屏 canvas |
| `activeLayerId` | `Ref<string>` | `''` | 当前编辑层的 ID |
| `activeLayer` | `ComputedRef<MaskLayer\|null>` | — | 当前编辑层对象 |
| `showOverlay` | `Ref<boolean>` | true | 是否显示蒙版叠加预览 |
| `maskActive` | `Ref<boolean>` | false | 蒙版是否激活（旧版标志位） |
| `compositeCanvas` | `Ref<HTMLCanvasElement\|null>` | null | 所有启用层 multiply 合成后的 canvas（兼容旧接口） |
| `imgWidth/imgHeight` | `Ref<number>` | 0 | 图片原始尺寸，所有层 canvas 共用此尺寸 |

**MaskLayer 结构：**

| 字段 | 类型 | 作用 |
|------|------|------|
| `id` | `string` | 唯一标识 |
| `name` | `string` | 层名称（可双击编辑） |
| `enabled` | `boolean` | 是否启用（禁用时不参与处理链） |
| `type` | `'linear'\|'radial'` | 蒙版类型 |
| `linear` | `LinearMaskParams` | 线性渐变参数（x1,y1,x2,y2,feather） |
| `radial` | `RadialMaskParams` | 径向渐变参数（cx,cy,rx,ry,angle,feather,invert） |
| `adjustments` | `AdjustmentValues` | 该层独立调色参数（局部调色） |
| `canvas` | `HTMLCanvasElement\|null` | 离屏 canvas，存储该层渐变蒙版像素数据，不可序列化 |

---

### 6. 裁切状态（WorkstationPage）

| 字段 | 类型 | 默认值 | 作用 |
|------|------|--------|------|
| `currentCropState` | `Ref<CropState>` | DEFAULT_CROP_STATE | 当前裁切状态，切换图片时从 IndexedDB 恢复 |
| `cropPreviewBackup` | `string\|null` | null | 进入裁切模式时备份的 imageSrc，取消时恢复；只写一次，所有取消操作统一恢复到此值 |
| `cropToolActive` | `Ref<boolean>` | false | 裁切框是否激活显示 |
| `cropRatio` | `Ref<number\|null>` | null | 当前选中的裁切比例 |
| `transformPending` | `Ref<boolean>` | false | 旋转/翻转是否有待确认的操作，true 时显示确认/取消操作栏 |
| `activePanelTab` | `Ref<string>` | `'basic'` | 右侧面板当前激活的 tab |
| `adjSliderDragging` | `Ref<boolean>` | false | 蒙版局部调色滑块拖动中，true 时临时隐藏蒙版 overlay |
| `transformCache` | `Map<string, string>` | 空 | 旋转/翻转变换结果缓存，key = `src后32位_rotate_flipH_flipV` |

**CropState 结构：**

| 字段 | 类型 | 作用 |
|------|------|------|
| `rotate` | `number` | 累计旋转角度（0/90/180/270） |
| `flipH` | `boolean` | 水平翻转 |
| `flipV` | `boolean` | 垂直翻转 |
| `rect` | `CropRect\|null` | 裁切区域像素坐标（null 表示未裁切） |

---

### 7. 网格线状态（useGridState）

| 字段 | 类型 | 默认值 | 作用 |
|------|------|--------|------|
| `settings.visible` | `boolean` | false | 是否显示网格线 |
| `settings.cols` | `number` | 3 | 竖线数量（分割列数） |
| `settings.rows` | `number` | 3 | 横线数量（分割行数） |
| `settings.color` | `string` | `'#ffffff'` | 线条颜色 |
| `settings.opacity` | `number` | 0.4 | 线条透明度（0~1） |
| `settings.lineWidth` | `number` | 1 | 线条宽度（px） |

---

### 8. ImagePreview 组件内部状态

| 字段 | 类型 | 作用 |
|------|------|------|
| `scale` | `Ref<number>` | 图片缩放比例（0.2~4） |
| `offsetX/offsetY` | `Ref<number>` | 图片平移偏移量（px） |
| `isPanning` | `Ref<boolean>` | 是否正在拖拽平移 |
| `imageReady` | `Ref<boolean>` | 图片是否已绘制到 canvas，控制网格线渲染时机 |
| `gridExpanded` | `Ref<boolean>` | 网格设置面板是否展开 |
| `gridPanelX/Y` | `Ref<number\|null>` | 网格面板拖拽位置（null = 默认右上角） |
| `gridOpenUpward` | `Ref<boolean>` | 网格面板是否向上展开（底部空间不足时） |
| `isDragOver` | `Ref<boolean>` | 文件拖拽悬停状态 |

## 二、持久化存储

### 1. IndexedDB（WorkstationDB v5，Store: images）

数据库名：`WorkstationDB`，版本：`5`，主键：`id`

| 字段 | 类型 | 是否必填 | 作用 |
|------|------|----------|------|
| `id` | `number` | 必填 | 主键，Date.now() + random |
| `name` | `string` | 必填 | 图片文件名 |
| `blob` | `Blob` | 必填 | 原始图片二进制，永不覆盖，刷新后重建 File 对象用 |
| `src` | `string` | 必填 | 原始图片 dataUrl，永不覆盖，复原原图时从此读取 |
| `editedSrc` | `string` | 可选 | 裁切/旋转/翻转后的图片 dataUrl，有则优先用于预览 |
| `cropStateJson` | `string` | 可选 | CropState 的 JSON 序列化，记录旋转/翻转/裁切区域 |
| `adjustmentsJson` | `string` | 可选 | 全量调色参数 JSON（基础调色 + HSL + 蒙版层参数） |
| `thumbnail` | `string` | 可选 | 200px 缩略图 dataUrl，全览区展示用 |
| `uploadTime` | `Date` | 必填 | 首次上传时间，排序用，永不覆盖 |
| `lastModified` | `Date` | 必填 | 最后修改时间 |
| `fileHash` | `string` | 可选 | `name_size_type` 去重哈希，上传时查重用 |

**索引：** `uploadTime`（排序）、`name`（查询）、`fileHash`（去重）

**adjustmentsJson 内容结构：**
```json
{
  "adjustments": { "brightness": 0, "contrast": 0, "saturation": 0, "vibrance": 0, "hue": 0, "temperature": 0, "clarity": 0 },
  "hslAdjustments": {
    "red":    { "hue": 0, "saturation": 0, "lightness": 0 },
    "orange": { "hue": 0, "saturation": 0, "lightness": 0 },
    "yellow": { "hue": 0, "saturation": 0, "lightness": 0 },
    "green":  { "hue": 0, "saturation": 0, "lightness": 0 },
    "cyan":   { "hue": 0, "saturation": 0, "lightness": 0 },
    "blue":   { "hue": 0, "saturation": 0, "lightness": 0 },
    "purple": { "hue": 0, "saturation": 0, "lightness": 0 }
  },
  "mask": [
    {
      "id": "mask-1", "name": "线性 1", "enabled": true, "type": "linear",
      "linear": { "x1": 0.2, "y1": 0.5, "x2": 0.8, "y2": 0.5, "feather": 0.1 },
      "radial": { "cx": 0.5, "cy": 0.5, "rx": 0.25, "ry": 0.25, "angle": 0, "feather": 0.15, "invert": false },
      "adjustments": { "brightness": 0, "contrast": 0, "saturation": 0, "vibrance": 0, "hue": 0, "temperature": 0, "clarity": 0 }
    }
  ]
}
```

注意：蒙版的 `canvas` 字段不序列化，恢复时根据参数重新调用 `generateLayerMask` 重建。

**cropStateJson 内容结构：**
```json
{ "rotate": 90, "flipH": false, "flipV": false, "rect": { "x": 100, "y": 50, "w": 800, "h": 600 } }
```

**写入时机：**

| 字段 | 写入时机 |
|------|----------|
| `blob` / `src` / `thumbnail` / `fileHash` / `uploadTime` | 上传时一次性写入，永不覆盖 |
| `editedSrc` / `cropStateJson` | 裁切/旋转/翻转确认时写入；复原原图时删除 |
| `adjustmentsJson` | 调色参数变化后防抖 500ms 自动写入 |
| `lastModified` | 每次写入时更新 |

---

### 2. localStorage

| Key | 内容 | 作用 |
|-----|------|------|
| `workstation-layout-settings` | `{ leftPanelWidth, galleryHeight, timestamp }` | 面板宽度和全览区高度，拖拽结束时保存，刷新后恢复 |
| `workstation-grid-settings` | `{ visible, cols, rows, color, opacity, lineWidth }` | 网格线配置，任意参数变化时自动保存 |

---

## 三、数据流向总结

```
用户操作
  │
  ├─ 上传图片 → 内存 uploadedImages + IndexedDB (blob/src/thumbnail)
  │
  ├─ 调色滑块 → 内存 adjustments/hslAdjustments
  │              → Worker 处理链 → 内存 processedSrc（预览）
  │              → 防抖 500ms → IndexedDB adjustmentsJson
  │
  ├─ 蒙版操作 → 内存 maskLayers（含 canvas）
  │              → Worker 处理链（lerp 混合）→ 内存 processedSrc
  │              → 防抖 500ms → IndexedDB adjustmentsJson（含蒙版参数，不含 canvas）
  │
  ├─ 裁切/旋转/翻转确认 → 内存 imageSrc + currentCropState
  │                        → IndexedDB editedSrc + cropStateJson
  │
  ├─ 复原原图 → 内存 imageSrc = originalSrc
  │             → IndexedDB 删除 editedSrc + cropStateJson
  │
  ├─ 网格线设置 → 内存 gridSettings
  │               → localStorage workstation-grid-settings（实时）
  │
  └─ 面板拖拽 → 内存 leftPanelWidth/galleryHeight
                → localStorage workstation-layout-settings（拖拽结束）
```
