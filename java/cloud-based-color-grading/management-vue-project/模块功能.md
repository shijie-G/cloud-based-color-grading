# Vue 文件职责说明

本文档记录当前项目中每个 `.vue` 文件的主要职责。路径按模块分组，便于后续维护时快速定位页面、容器组件和基础控件。

## 应用入口与公共组件

| 文件 | 职责 |
| --- | --- |
| `src/App.vue` | 主应用根组件，只渲染 `router-view`，并提供全局页面尺寸、盒模型和隐藏滚动的基础样式。 |
| `src/LoginApp.vue` | 独立登录实例根组件，只承载登录路由的 `router-view`，用于 `/login.html` 登录入口。 |
| `src/StationApp.vue` | station 实例根组件，固定展示 `GlobalNavbar`，并在导航栏下方渲染业务路由内容。 |
| `src/components/GlobalNavbar.vue` | 全局顶部导航栏，负责 logo、首页/图库/工作站/个性化导航、当前路由高亮和右侧用户头像区域。 |
| `src/components/HelloWorld.vue` | Vite 初始化示例组件，当前业务代码未引用，保留为示例/占位文件。 |

## 登录模块

| 文件 | 职责 |
| --- | --- |
| `src/views/login/LoginPage.vue` | 登录页，使用 Element Plus 表单收集账号和密码，调用 `useLoginForm` 完成校验、登录提交、加载状态控制，并在挂载后自动聚焦账号输入框。 |

## 首页模块

| 文件 | 职责 |
| --- | --- |
| `src/views/home/Home.vue` | 当前首页主页面，包含全局导航、动态 canvas hero、功能模块入口、数据统计、调色能力展示、处理链展示、工作流程和页脚。 |
| `src/views/home/components/HeroSection.vue` | 首页 hero 区块组件，展示品牌标题、说明文案和进入工作站/查看演示的动作事件；当前未被 `Home.vue` 直接引用。 |
| `src/views/home/components/FeaturesSection.vue` | 首页功能特性区块，列出调色、图库、导出等能力卡片并提供 feature 点击事件；当前未被 `Home.vue` 直接引用。 |
| `src/views/home/components/WorkflowSection.vue` | 首页工作流程区块，展示从上传到导出的步骤，并向外发送步骤点击事件；当前未被 `Home.vue` 直接引用。 |
| `src/views/home/components/ShowcaseSection.vue` | 首页作品/场景展示区块，用于展示调色案例卡片；当前未被 `Home.vue` 直接引用。 |

## 图库模块

| 文件 | 职责 |
| --- | --- |
| `src/views/gallery/GalleryPage.vue` | 图库首页，负责加载相册、未分配图片数量和相册封面，处理新建/重命名/删除相册、拖拽上传图片或 `.gsj` 工程文件，并跳转到相册详情。 |
| `src/views/gallery/components/AlbumList.vue` | 相册列表容器，按月份分组展示相册卡片，包含未分配图片入口、新建相册入口，并转发选择、重命名、删除、上传事件。 |
| `src/views/gallery/components/AlbumCard.vue` | 单个相册卡片，展示封面、相册名、创建日期，支持卡片点击、重命名、删除和将图片拖放到该相册上传。 |
| `src/views/gallery/components/AlbumSelector.vue` | 相册选择弹窗，用于将图片移动到其他相册；会过滤当前相册，支持取消和选择目标相册。 |
| `src/views/gallery/components/ImageBrowser.vue` | 图片浏览容器，将顶部快速筛选、主图查看、缩略图条和批量操作栏组合在一起，负责当前图片、筛选计数和键盘左右切换。 |
| `src/views/gallery/components/ImageViewer.vue` | 图库图片查看器，展示单张图片，提供缩放、旋转、平移、收藏、删除、移动等操作入口。 |
| `src/views/gallery/components/ThumbnailStrip.vue` | 横向缩略图条，展示图片列表、当前选中项和多选状态，支持点击选择、右键菜单事件和自动滚动到当前图片。 |
| `src/views/gallery/components/QuickFilterBar.vue` | 快速筛选栏，按全部、收藏、回收站等模式展示数量并切换筛选条件。 |
| `src/views/gallery/components/BatchActionBar.vue` | 批量操作栏，选中多张图片时显示，提供批量收藏、移动、删除和清空选择事件。 |

## 相册详情模块

| 文件 | 职责 |
| --- | --- |
| `src/views/album/AlbumDetailPage.vue` | 单个相册详情页，依据路由参数加载相册图片，管理多选、收藏、永久删除、设为封面、移动到其他相册、拖拽上传图片和导入 `.gsj` 工程文件。 |
| `src/views/album/components/ImageBrowser.vue` | 相册详情内的图片浏览容器，组合筛选栏、查看器、缩略图条和批量操作栏；职责与图库同名组件类似，但类型引用来自图库模块并用于相册详情路径。 |
| `src/views/album/components/ImageViewer.vue` | 相册详情图片查看器，除了查看、缩放、旋转、平移、收藏、删除、移动、设为封面外，还会加载调色参数、裁切、蒙版、滤镜和个性化图层，提供图片导出和 `.gsj` 工程导出入口。 |
| `src/views/album/components/ThumbnailStrip.vue` | 相册详情缩略图条，展示当前相册图片列表，支持选择、多选状态、右键菜单和滚动定位当前图片。 |
| `src/views/album/components/QuickFilterBar.vue` | 相册详情快速筛选栏，负责切换全部/收藏/回收站等筛选模式并展示对应计数。 |
| `src/views/album/components/BatchActionBar.vue` | 相册详情批量操作栏，显示已选数量，并提供批量收藏、转移、永久删除和清空选择。 |
| `src/views/album/components/AlbumSelector.vue` | 相册详情中的目标相册选择弹窗，用于图片转移；逻辑与图库同名组件基本一致，但使用绝对类型路径。 |
| `src/views/album/components/export/ExportModal.vue` | 导出图片弹窗，左侧显示导出预览，右侧承载导出设置；负责估算文件大小、加载个性化图层、叠加水印预览，并调用 `useImageExport` 执行导出。 |
| `src/views/album/components/export/ExportSettings.vue` | 导出参数表单，负责格式、质量、缩放、DPI、背景、是否包含个性化图层和水印配置的编辑，并向父组件同步完整设置。 |
| `src/views/album/components/export/WatermarkConfig.vue` | 水印配置子表单，负责水印开关、文本、位置、颜色、透明度、缩放和加粗等配置项。 |

## 工作站模块

| 文件 | 职责 |
| --- | --- |
| `src/views/workstation/WorkstationPage.vue` | 调色工作站主页面，统筹图片列表、选图、上传、基础调色、HSL、蒙版、滤镜、网格、裁切/旋转/翻转、对比原图、撤销/重做、自动保存和 IndexedDB 持久化。 |
| `src/views/workstation/components/ImageDisplay.vue` | 工作站左侧显示区域容器，组合主预览、底部图片全览和全览高度拖拽条，并向父页面转发选图、上传、布局、蒙版、裁切、对比和相册切换事件。 |
| `src/views/workstation/components/ImagePreview.vue` | 主预览画布，负责把原图/处理后图片绘制到 canvas，支持滚轮缩放、拖拽平移、双击缩放重置、拖拽上传、蒙版交互层、网格叠加、裁切工具和裁切确认栏。 |
| `src/views/workstation/components/ImageGallery.vue` | 底部图片全览，展示当前相册或全部图片的缩略图，支持相册下拉切换、添加图片、重置布局和原图对比开关。 |
| `src/views/workstation/components/AdjustPanel.vue` | 右侧调整面板容器，管理基础调色、裁切、蒙版、滤镜四个 tab，并负责网格显示开关和各子面板事件转发。 |
| `src/views/workstation/components/BasicAdjustPanel.vue` | 基础调色面板组合组件，包含 RGB 分析、基础参数滑块、HSL 控件和操作按钮。 |
| `src/views/workstation/components/AdjustmentControls.vue` | 基础调色滑块组，负责亮度、对比度、高光、阴影、白色、黑色、饱和度、自然饱和度、色相、色温、色调、清晰度、去朦胧等参数的编辑和单项重置。 |
| `src/views/workstation/components/HSLControls.vue` | HSL 精调控件，按红、橙、黄、绿、青、蓝、紫七个颜色范围分别调节色相、饱和度和明度，并支持重置当前轴或全部 HSL 参数。 |
| `src/views/workstation/components/RGBAnalysis.vue` | RGB 直方图分析组件，从原图或处理后图片计算通道分布，绘制直方图，支持显示/隐藏 R/G/B 通道和鼠标悬浮提示。 |
| `src/views/workstation/components/ActionButtons.vue` | 基础操作按钮组，负责选择图片文件、重置参数、按 PNG/JPEG 保存导出，并控制按钮禁用状态。 |
| `src/views/workstation/components/CropPanel.vue` | 裁切操作面板，提供自由/固定比例裁切、旋转 90 度、水平/垂直翻转和复原原图等事件。 |
| `src/views/workstation/components/CropTool.vue` | 画布上的裁切框交互层，按图片显示区域定位，支持拖拽移动、八方向缩放、固定比例约束、Enter 提交和 Esc 取消。 |
| `src/views/workstation/components/MaskAdjustPanel.vue` | 当前使用的蒙版控制面板，负责蒙版图层列表、添加线性/径向蒙版、启用/禁用、重命名、删除、反转、清除、显示叠加层和每层独立调色参数。 |
| `src/views/workstation/components/MaskCanvas.vue` | 画布上的蒙版交互层，负责线性/径向蒙版的创建、拖拽、缩放、旋转、中心移动和叠加预览绘制。 |
| `src/views/workstation/components/MaskControls.vue` | 旧版蒙版控件，提供蒙版激活、图层列表和蒙版参数控制；当前主流程已由 `MaskAdjustPanel.vue` 接管。 |
| `src/views/workstation/components/FilterPanel.vue` | 滤镜面板，编辑模糊、锐化、风格化、颗粒、暗角等滤镜参数，支持预设选择并在鼠标释放时提交历史记录。 |
| `src/views/workstation/components/GridPanel.vue` | 网格设置面板，提供三等分、九宫格、黄金比预设，以及行列数、颜色、透明度、线宽调整。 |
| `src/views/workstation/components/GridOverlay.vue` | 图片预览上的网格绘制层，根据当前 canvas 尺寸、缩放和平移状态绘制与图片对齐的网格线。 |
| `src/views/workstation/components/GalleryResizer.vue` | 图片全览区域的水平拖拽分割线，负责把鼠标位置转换为底部图库高度并通知父组件保存布局。 |
| `src/views/workstation/components/PanelResizer.vue` | 左右面板之间的垂直拖拽分割线，负责调整左侧预览区域宽度并通知父组件开始/结束拖拽。 |
| `src/views/workstation/components/SliderRow.vue` | 通用滑块行组件，展示标签、范围、数值和单位，并向父组件发出单个数值更新事件。 |
| `src/views/workstation/components/TopNavbar.vue` | 工作站顶部导航栏占位组件，当前在 `WorkstationPage.vue` 中被注释，未参与实际渲染。 |
| `src/views/workstation/components/UploadSection.vue` | 旧版上传区域组件，负责显示上传提示并触发文件选择；当前上传入口已整合进 `ActionButtons.vue` 和预览区拖拽上传。 |
| `src/views/workstation/components/RGBHistogram.vue` | 空文件，当前没有实现内容，作为 RGB 直方图相关功能的预留/遗留文件。 |

## 个性化模块

| 文件 | 职责 |
| --- | --- |
| `src/views/personalize/PersonalizePage.vue` | 个性化设计主页面，选择图库图片作为底图，复用调色处理链生成调色后图片，管理文字/形状/贴纸图层、图层存储、面板宽度拖拽和清空画布。 |
| `src/views/personalize/components/AssetPanel.vue` | 左侧素材库面板，提供从相册选择底图、添加文字、添加多种形状和选择贴纸素材的入口。 |
| `src/views/personalize/components/CanvasArea.vue` | 中央设计画布，负责绘制底图 canvas，渲染图层，支持画布缩放/平移、图层选择、拖拽移动、双击编辑文字、图层缩放和旋转。 |
| `src/views/personalize/components/TransformControls.vue` | 图层变换控件，显示在选中图层周围，负责缩放手柄和旋转手柄交互，并向画布同步尺寸和旋转角度。 |
| `src/views/personalize/components/LayerPanel.vue` | 右侧图层列表，展示所有图层，支持选择、拖拽排序、显示/隐藏、锁定/解锁、复制和删除。 |
| `src/views/personalize/components/PropertyPanel.vue` | 右侧属性面板，根据选中图层类型编辑名称、透明度、位置、大小、旋转、文字样式、形状填充/描边和图片属性。 |
| `src/views/personalize/components/ImageSelector.vue` | 图片选择弹窗，从 IndexedDB 图库读取图片并供个性化页面选择底图。 |
| `src/views/personalize/components/StickerSelector.vue` | 贴纸选择器组件，按分类展示贴纸并发出贴纸选择事件；当前主素材面板内已有贴纸列表，该组件偏备用/独立选择器。 |

## 备注

- `src/views/gallery/components/*` 与 `src/views/album/components/*` 中有多组同名组件，职责相近，但前者偏图库列表/通用浏览，后者用于相册详情并扩展了导出、设为封面、工程文件等相册场景能力。
- `TopNavbar.vue`、`UploadSection.vue`、`MaskControls.vue`、`RGBHistogram.vue` 属于工作站旧版或预留组件，当前主页面没有直接使用其中大部分。
- `Home.vue` 当前已经内联实现首页主体内容，`views/home/components` 下的四个区块组件更像早期拆分或备用组件。
