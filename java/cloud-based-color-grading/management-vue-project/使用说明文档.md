## 系统简介

这是一个基于 Vue 3 + TypeScript + Element Plus 构建的现代化菜单角色权限管理系统（RBAC），提供完整的角色、菜单、权限管理功能。

### 主要特性

- 🎨 现代化科技风格 UI 设计（玻璃态效果、渐变、发光效果）
- 🔐 完整的 RBAC 权限控制系统
- 📱 响应式设计，支持移动端和桌面端
- ⚡ 基于 Vite 的快速开发体验
- 🧪 完整的测试覆盖（205+ 测试用例）
- 🛡️ 路由守卫保护，安全可靠

## 快速开始

### 环境要求

- Node.js >= 16.0.0
- npm >= 8.0.0

### 安装依赖

```bash
cd management-vue-project
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:5173 即可看到登录页面。

### 构建生产版本

```bash
npm run build
```

### 运行测试

```bash
# 运行所有测试
npm run test

# 运行测试并查看覆盖率
npm run test:coverage
```

## 功能模块

### 1. 用户登录

**访问路径**: `/login`

**功能说明**:
- 用户身份验证
- 自动跳转到目标页面
- 记住登录状态（Token 持久化）

**使用方法**:
1. 输入用户名和密码
2. 点击"登录"按钮
3. 登录成功后自动跳转到角色管理页面

**注意**: 当前为模拟登录，输入任意用户名和密码即可登录。实际使用时需要连接后端 API。

---

### 2. 角色管理

**访问路径**: `/role`

**权限要求**: `system:role:view`

**功能说明**:
- 查看角色列表
- 创建新角色
- 编辑角色信息
- 删除角色
- 为角色分配权限

#### 操作步骤

**创建角色**:
1. 点击页面右上角"新增角色"按钮
2. 填写角色信息：
   - 角色名称（必填）
   - 角色编码（必填，如 `ROLE_ADMIN`）
   - 角色描述（可选）
   - 状态（启用/禁用）
3. 点击"确定"保存

**编辑角色**:
1. 在角色列表中找到目标角色
2. 点击操作列的"编辑"按钮
3. 修改角色信息
4. 点击"确定"保存

**删除角色**:
1. 在角色列表中找到目标角色
2. 点击操作列的"删除"按钮
3. 确认删除操作

**分配权限**:
1. 在角色列表中找到目标角色
2. 点击操作列的"分配权限"按钮
3. 在权限树中勾选需要的权限
4. 点击"确定"保存

**搜索角色**:
- 在搜索框中输入角色名称或编码
- 点击"搜索"按钮
- 点击"重置"清空搜索条件

---

### 3. 菜单管理

**访问路径**: `/menu`

**权限要求**: `system:menu:view`

**功能说明**:
- 查看菜单树形结构
- 创建菜单/按钮
- 编辑菜单信息
- 删除菜单
- 为菜单关联权限

#### 操作步骤

**创建菜单**:
1. 点击页面右上角"新增菜单"按钮（创建顶级菜单）
   或点击某个菜单行的"新增"按钮（创建子菜单）
2. 填写菜单信息：
   - 菜单名称（必填）
   - 菜单类型（目录/菜单/按钮）
   - 路由路径（菜单类型时必填）
   - 组件路径（菜单类型时必填）
   - 图标（可选）
   - 排序号（数字越小越靠前）
   - 状态（显示/隐藏）
3. 点击"确定"保存

**编辑菜单**:
1. 在菜单树中找到目标菜单
2. 点击操作列的"编辑"按钮
3. 修改菜单信息
4. 点击"确定"保存

**删除菜单**:
1. 在菜单树中找到目标菜单
2. 点击操作列的"删除"按钮
3. 确认删除操作
4. **注意**: 删除父菜单会同时删除所有子菜单

**关联权限**:
1. 在菜单树中找到目标菜单
2. 点击操作列的"权限"按钮
3. 在权限列表中勾选需要关联的权限
4. 点击"确定"保存

**菜单类型说明**:
- **目录**: 不对应具体页面，用于组织菜单结构
- **菜单**: 对应一个页面路由
- **按钮**: 页面内的操作按钮，用于细粒度权限控制

---

### 4. 权限管理

**访问路径**: `/permission`

**权限要求**: `system:permission:view`

**功能说明**:
- 查看权限列表
- 创建新权限
- 编辑权限信息
- 删除权限
- 搜索和筛选权限

#### 操作步骤

**创建权限**:
1. 点击页面右上角"新增权限"按钮
2. 填写权限信息：
   - 权限名称（必填）
   - 权限编码（必填，如 `system:user:add`）
   - 权限类型（菜单/按钮/API）
   - 权限描述（可选）
3. 点击"确定"保存

**编辑权限**:
1. 在权限列表中找到目标权限
2. 点击操作列的"编辑"按钮
3. 修改权限信息
4. 点击"确定"保存

**删除权限**:
1. 在权限列表中找到目标权限
2. 点击操作列的"删除"按钮
3. 确认删除操作

**搜索权限**:
- 在搜索框中输入权限名称或编码
- 选择权限类型进行筛选
- 点击"搜索"按钮
- 点击"重置"清空搜索条件

**权限编码规范**:
- 格式: `模块:资源:操作`
- 示例: 
  - `system:user:view` - 查看用户
  - `system:user:add` - 添加用户
  - `system:user:edit` - 编辑用户
  - `system:user:delete` - 删除用户

## 技术架构

### 前端技术栈

- **框架**: Vue 3.4+ (Composition API)
- **语言**: TypeScript 5.0+
- **构建工具**: Vite 5.0+
- **UI 组件库**: Element Plus 2.5+
- **状态管理**: Pinia 2.1+
- **路由**: Vue Router 4.2+
- **HTTP 客户端**: Axios 1.6+
- **测试框架**: Vitest + Vue Test Utils

```

│   ├── layout/           # 布局组件
│   ├── router/           # 路由配置
│   ├── stores/           # Pinia 状态管理

│   ├── views/            # 页面组件
│   ├── App.vue           # 根组件
│   ├── main.ts           # 应用入口
```

### 核心模块说明

**API 层** (`src/api/`):

## 常见问题

### 1. 登录后无法访问某个页面

**原因**: 当前用户没有该页面所需的权限。

**解决方法**:
1. 检查用户的角色是否包含所需权限
2. 在角色管理中为角色分配相应权限
3. 重新登录使权限生效

### 2. 页面显示空白

**可能原因**:
- 路由配置错误
- 组件加载失败
- 权限验证失败

**解决方法**:
1. 打开浏览器控制台查看错误信息
2. 检查路由配置是否正确
3. 确认用户已登录且有访问权限

### 3. 如何连接后端 API

**步骤**:
1. 修改 `src/utils/http.ts` 中的 `baseURL`
2. 更新各个 API 文件中的接口调用
3. 移除 mock 数据，使用真实 API 响应

**示例**:
```typescript
// src/utils/http.ts
const http = axios.create({
  baseURL: 'http://your-api-server.com/api', // 修改为实际 API 地址
  timeout: 10000
})
```

### 4. 如何自定义主题颜色

**方法**:
1. 修改 Element Plus 主题变量
2. 更新全局样式文件

**示例**:
```css
/* src/style.css */
:root {
  --el-color-primary: #409eff; /* 修改主题色 */
}
```

### 5. 如何添加新的菜单页面

**步骤**:
1. 在 `src/views/` 下创建新页面组件
2. 在 `src/router/index.ts` 中添加路由配置
3. 在菜单管理中创建对应菜单项
4. 为菜单关联所需权限

**示例**:
```typescript
// src/router/index.ts
{
  path: 'user',
  name: 'UserManagement',
  component: () => import('@/views/user/index.vue'),
  meta: { 
    title: '用户管理', 
    icon: 'user',
    permission: 'system:user:view'
  }
}
```

### 6. 测试失败怎么办

**排查步骤**:
1. 运行 `npm run test` 查看具体错误
2. 检查测试环境配置
3. 确认依赖安装完整

**常见问题**:
- 缺少测试依赖: 运行 `npm install`
- 环境变量未设置: 检查 `.env.test` 文件
- 组件导入路径错误: 检查 `tsconfig.json` 中的路径别名

## 开发建议

### 代码规范

- 使用 TypeScript 严格模式
- 遵循 Vue 3 Composition API 最佳实践
- 组件命名使用 PascalCase
- 文件命名使用 kebab-case

### 性能优化

- 使用路由懒加载
- 合理使用 `computed` 和 `watch`
- 避免不必要的响应式数据
- 使用虚拟滚动处理大列表

### 安全建议

- 所有 API 请求添加 Token 验证
- 敏感操作需要二次确认
- 定期更新依赖包
- 使用 HTTPS 协议
