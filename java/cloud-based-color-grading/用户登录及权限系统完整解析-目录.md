## 快速导航

### 核心流程

```
用户登录 → JWT生成 → Token验证 → 权限检查 → 菜单加载
```

### 关键技术

- **认证**: BCrypt密码加密 + JWT Token
- **授权**: RBAC模型（用户-角色-权限）
- **缓存**: Redis（Token + 权限）
- **网关**: Spring Cloud Gateway
- **安全**: 账户锁定 + 审计日志
