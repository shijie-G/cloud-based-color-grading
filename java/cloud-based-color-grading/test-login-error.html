登录错误处理测试指南

🔧 修复内容

✅ 已修复 authApi.ts
- 现在会正确创建带有 response 属性的错误对象
- 业务错误（如密码错误）会被正确识别为 HTTP 401 错误
✅ 已优化 useLoginForm.ts
- 增强了错误处理逻辑
- 现在会显示后端返回的具体错误消息
- 确保所有类型的错误都有相应的提示

🧪 测试场景

场景1: 用户名或密码错误
输入错误的用户名/密码 → 应显示 "手机号/邮箱或密码错误"
场景2: 网络连接失败
关闭后端服务 → 应显示 "网络连接失败，请检查网络设置"
场景3: 服务器内部错误
后端返回500错误 → 应显示 "登录失败，请稍后重试"
场景4: 账户被锁定
后端返回403错误 → 应显示 "账户已被锁定或禁用，请联系管理员"

🚀 测试步骤

  1. 启动前端开发服务器: npm run dev
  2. 打开浏览器访问 http://localhost:3000
  3. 在登录页面输入错误的用户名和密码
  4. 点击登录按钮
  5. 检查是否显示错误提示弹窗

🔍 调试信息

如果仍然没有显示错误提示，请：

  • 打开浏览器开发者工具的 Console 标签
  • 查看是否有 JavaScript 错误
  • 检查网络请求是否正常发送
  • 确认 Element Plus 的 ElMessage 组件是否正常工作
