# Common 模块说明

## 模块概述

**模块名称：** common（公共模块）  
**类型：** 依赖库（不独立运行）  
**职责：** 提供共享实体类、DTO、工具类、常量定义

Common模块是所有微服务的基础依赖，包含了系统中通用的数据模型、数据传输对象、工具类和常量定义。

## 核心组件

### 1. 实体类（Entity）

#### User（用户实体）

**类路径：** `cn.gsjgsj.common.entity.User`

**字段说明：**
```java
public class User {
    private Long id;                    // 用户ID
    private String username;            // 用户名（唯一）
    private String password;            // 密码（BCrypt加密）
    private String nickname;            // 昵称
    private String email;               // 邮箱
    private String phone;               // 手机号
    private Integer status;             // 状态（0-正常 1-禁用）
    private LocalDateTime createTime;   // 创建时间
    private LocalDateTime lastLoginTime; // 最后登录时间
}
```

**注解：**
- `@TableName("sys_user")`: 指定数据库表名
- `@TableId(type = IdType.AUTO)`: 主键自增
- `@Data`: Lombok自动生成getter/setter

#### Result（统一响应结果）

**类路径：** `cn.gsjgsj.common.dto.Result`

**字段说明：**
```java
public class Result<T> {
    private Integer code;               // 状态码
    private String message;             // 消息
    private T data;                     // 数据
}
```

**静态方法：**
```java
// 成功响应（无数据）
public static <T> Result<T> success()

// 成功响应（有数据）
public static <T> Result<T> success(T data)

// 失败响应（默认消息）
public static <T> Result<T> error()

// 失败响应（自定义消息）
public static <T> Result<T> error(String message)

// 失败响应（自定义状态码和消息）
public static <T> Result<T> error(Integer code, String message)
```

**使用示例：**
```java
// 成功
return Result.success(user);

// 失败
return Result.error("用户不存在");
return Result.error(404, "资源未找到");
```

### 3. 常量定义（Constant）

#### RedisKeyConstants（Redis键常量）

**类路径：** `cn.gsjgsj.common.constant.RedisKeyConstants`

**常量定义：**
```java
public class RedisKeyConstants {
    // 令牌前缀
    public static final String TOKEN_PREFIX = "token:";
    
    // 权限缓存前缀
    public static final String PERMISSION_PREFIX = "permission:";
    
    // 登录失败计数前缀
    public static final String LOGIN_FAIL_PREFIX = "login:fail:";
    
    // 账户锁定前缀
    public static final String ACCOUNT_LOCKED_PREFIX = "account:locked:";
    
    // 生成令牌键
    public static String getTokenKey(Long userId) {
        return TOKEN_PREFIX + userId;
    }
    
    // 生成权限缓存键
    public static String getPermissionKey(Long userId) {
        return PERMISSION_PREFIX + userId;
    }
    
    // 生成登录失败计数键
    public static String getLoginFailKey(String username) {
        return LOGIN_FAIL_PREFIX + username;
    }
    
    // 生成账户锁定键
    public static String getAccountLockedKey(String username) {
        return ACCOUNT_LOCKED_PREFIX + username;
    }
}
```

### 4. 工具类（Util）

#### JwtTokenProvider（JWT令牌提供者）

**类路径：** `cn.gsjgsj.common.util.JwtTokenProvider`

**主要方法：**
```java
// 生成JWT令牌
public String generateToken(Long userId, String username, List<String> roles)

// 从令牌中提取用户ID
public Long getUserIdFromToken(String token)

// 从令牌中提取用户名
public String getUsernameFromToken(String token)

// 从令牌中提取角色列表
public List<String> getRolesFromToken(String token)

// 验证令牌是否有效
public boolean validateToken(String token)

// 获取令牌剩余有效期（毫秒）
public long getRemainingValidity(String token)

// 检查令牌是否需要刷新
public boolean needsRefresh(String token)
```

**配置属性：**
```java
@Value("${jwt.secret}")
private String secretKey;

@Value("${jwt.expiration}")
private long validityInMilliseconds;

@Value("${jwt.refresh-threshold}")
private long refreshThreshold;
```

**使用示例：**
```java
// 生成令牌
String token = jwtTokenProvider.generateToken(
    userId, 
    username, 
    Arrays.asList("ROLE_USER", "ROLE_ADMIN")
);

// 验证令牌
boolean isValid = jwtTokenProvider.validateToken(token);

// 提取用户信息
Long userId = jwtTokenProvider.getUserIdFromToken(token);
String username = jwtTokenProvider.getUsernameFromToken(token);
List<String> roles = jwtTokenProvider.getRolesFromToken(token);

// 检查是否需要刷新
if (jwtTokenProvider.needsRefresh(token)) {
    String newToken = jwtTokenProvider.generateToken(userId, username, roles);
}
```

### 5. 公共服务（Service）

#### RedisService（Redis服务）

**类路径：** `cn.gsjgsj.common.service.RedisService`

**主要方法：**
```java
// 存储令牌
public void saveToken(Long userId, String token, long expiration)

// 获取令牌
public String getToken(Long userId)

// 删除令牌
public void deleteToken(Long userId)

// 存储权限
public void savePermissions(Long userId, List<Permission> permissions, long expiration)

// 获取权限
public List<Permission> getPermissions(Long userId)

// 清除权限
public void clearPermissions(Long userId)

// 增加登录失败次数
public long incrementLoginFailures(String username, long expiration)

// 获取登录失败次数
public long getLoginFailures(String username)

// 清除登录失败记录
public void clearLoginFailures(String username)

// 锁定账户
public void lockAccount(String username, long expiration)

// 检查账户是否被锁定
public boolean isAccountLocked(String username)

// 解锁账户
public void unlockAccount(String username)
```

**依赖：**
```java
@Autowired
private RedisTemplate<String, String> redisTemplate;

@Autowired
private ObjectMapper objectMapper;
```

**使用示例：**
```java
// 存储令牌
redisService.saveToken(userId, token, 7200);

// 获取令牌
String token = redisService.getToken(userId);

// 删除令牌
redisService.deleteToken(userId);

// 存储权限
redisService.savePermissions(userId, permissions, 1800);

// 获取权限
List<Permission> permissions = redisService.getPermissions(userId);

// 增加登录失败次数
long failures = redisService.incrementLoginFailures(username, 900);
if (failures >= 5) {
    redisService.lockAccount(username, 900);
}

// 检查账户是否被锁定
if (redisService.isAccountLocked(username)) {
    throw new IllegalStateException("账户已被锁定");
}
```

## 使用指南

### 1. 添加依赖

在其他模块的 `pom.xml` 中添加：

```xml
<dependency>
    <groupId>cn.gsjgsj</groupId>
    <artifactId>common</artifactId>
    <version>V1.0.0</version>
</dependency>
```

### 2. 使用实体类

```java
import cn.gsjgsj.common.entity.User;

User user = new User();
user.setUsername("testuser");
user.setPassword("password123");
```

### 3. 使用DTO

```java
import cn.gsjgsj.common.dto.Result;

@GetMapping("/users")
public Result<List<User>> getUsers() {
    List<User> users = userService.getAllUsers();
    return Result.success(users);
}
```

### 4. 使用工具类

```java
import cn.gsjgsj.common.util.JwtTokenProvider;

@Autowired
private JwtTokenProvider jwtTokenProvider;

String token = jwtTokenProvider.generateToken(userId, username, roles);
```

### 5. 使用常量

```java
import cn.gsjgsj.common.constant.RedisKeyConstants;

String tokenKey = RedisKeyConstants.getTokenKey(userId);
redisTemplate.opsForValue().set(tokenKey, token);
```

## 最佳实践

### 1. 实体类
- 使用Lombok简化代码
- 添加必要的验证注解
- 使用MyBatis-Plus注解

### 2. DTO
- 只包含必要的字段
- 添加验证注解
- 使用Builder模式（可选）

### 3. 常量
- 集中管理常量
- 使用有意义的命名
- 添加注释说明

### 4. 工具类
- 方法应该是静态的或无状态的
- 添加详细的注释
- 处理异常情况

## 常见问题

### Q1: 如何添加新的实体类？
**A:** 在 `entity` 包下创建新类，添加MyBatis-Plus注解。

### Q2: 如何修改JWT配置？
**A:** 修改各服务的 `application.yml` 中的 `jwt` 配置。

### Q3: 如何添加新的Redis键常量？
**A:** 在 `RedisKeyConstants` 类中添加新常量和生成方法。

### Q4: 如何自定义Result响应格式？
**A:** 修改 `Result` 类的字段和方法。

### Q5: 如何使用数据库脚本？
**A:** 在数据库中执行 `schema.sql` 和 `data.sql`。
