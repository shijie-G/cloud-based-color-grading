## 可删除文件清单

### 推荐立即删除

#### 1. 构建产物（约170-350 MB）
```bash
rm -rf auth-service/target
rm -rf authz-service/target
rm -rf gateway/target
rm -rf common/target
```

或使用Maven命令：
```bash
mvn clean
```

#### 2. 临时文件
```bash
rm auth-service/.jqwik-database
rm authz-service/.jqwik-database
rm gateway/.jqwik-database
rm common/.jqwik-database
```

### 可选删除

#### 3. 脚本文件
```bash
rm auth-service/run-controller-tests.bat
rm auth-service/run-controller-tests.sh
rm gateway/run-property-tests.sh
```

#### 4. 旧的README文档（创建新文档后）
```bash
rm auth-service/CONTROLLER_TESTS_README.md
rm auth-service/INTEGRATION_TEST_README.md
rm auth-service/INTEGRATION_TEST_SUMMARY.md
rm authz-service/ROLE_PERMISSION_CONTROLLERS_README.md
rm gateway/AUTHENTICATION_FILTER_README.md
```

### 绝对不要删除
- ❌ `src/` 目录（源代码）
- ❌ `pom.xml` 文件（Maven配置）
- ❌ `.gitignore` 文件（Git配置）
- ❌ `application.yml` 文件（配置文件）
