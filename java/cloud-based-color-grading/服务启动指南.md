本文档说明如何正确启动和运行整个微服务系统。

## 服务启动顺序

### 1. Auth Service (认证服务)
**端口：8081**

这是核心服务，负责用户认证、令牌管理和用户管理。

**启动方式：**
```bash
# 使用IDE运行
运行 auth-service/src/main/java/cn/gsjgsj/authservice/AuthServiceApplication.java

# 或使用Maven命令
cd auth-service
mvn spring-boot:run
```

**启动成功标志：**
- 控制台显示：`Started AuthServiceApplication in X seconds`
- Nacos控制台显示 `auth-service` 服务已注册
- 可访问：http://localhost:8081/actuator/health

**常见问题：**
- 如果启动失败，检查MySQL和Redis连接
- 确保端口8081未被占用

### 2. Authz Service (授权服务)
**端口：8082**

负责角色管理、权限管理和菜单管理。

**启动方式：**
```bash
# 使用IDE运行
运行 authz-service/src/main/java/cn/gsjgsj/authzservice/AuthzServiceApplication.java

# 或使用Maven命令
cd authz-service
mvn spring-boot:run
```

**启动成功标志：**
- 控制台显示：`Started AuthzServiceApplication in X seconds`
- Nacos控制台显示 `authz-service` 服务已注册
- 可访问：http://localhost:8082/actuator/health

**重要修复：**
- 已添加 `@MapperScan("cn.gsjgsj.authzservice.mapper")` 注解
- 确保MyBatis能正确扫描Mapper接口

### 3. Gateway (网关服务)
**端口：8080**

API网关，负责路由、JWT验证、权限检查等。

**启动方式：**
```bash
# 使用IDE运行
运行 gateway/src/main/java/cn/gsjgsj/gateway/GatewayApplication.java

# 或使用Maven命令
cd gateway
mvn spring-boot:run
```

**启动成功标志：**
- 控制台显示：`Started GatewayApplication in X seconds`
- 可访问：http://localhost:8080/actuator/health

**重要修复：**
- 已修复 `gateway.whitelist` 配置问题
- 白名单路径：/auth/login, /auth/register, /actuator/**, /favicon.ico

## 最近的修复

### 1. Gateway 白名单配置问题
**问题：** `Could not resolve placeholder 'gateway.whitelist'`

**解决方案：**
- 修改了 `JwtAuthenticationFilter.java` 中的 `@Value` 注解
- 使用SpEL表达式：`@Value("#{'${gateway.whitelist:/auth/login,/auth/register,/actuator/**,/favicon.ico}'.split(',')}")`
- 修改了 `application.yml` 中的配置格式为逗号分隔字符串

### 2. Authz Service 缺少 @MapperScan
**问题：** MyBatis无法找到Mapper接口

**解决方案：**
- 在 `AuthzServiceApplication.java` 中添加了 `@MapperScan("cn.gsjgsj.authzservice.mapper")` 注解

## 环境变量配置（可选）

如果需要修改默认配置，可以设置以下环境变量：

### 数据库配置
```bash
export DB_URL=jdbc:mysql://your-host:port/database
export DB_USERNAME=your-username
export DB_PASSWORD=your-password
```

### Redis配置
```bash
export REDIS_HOST=your-redis-host
export REDIS_PORT=6379
export REDIS_PASSWORD=your-password
export REDIS_DATABASE=0
```

### JWT配置
```bash
export JWT_SECRET=your-secret-key-at-least-256-bits
export JWT_EXPIRATION=7200000  # 2小时（毫秒）
export JWT_REFRESH_THRESHOLD=1800000  # 30分钟（毫秒）
```

### 服务URL配置（Gateway使用）
```bash
export AUTH_SERVICE_URL=http://localhost:8081
export AUTHZ_SERVICE_URL=http://localhost:8082
```

## 日志文件位置

所有服务的日志文件位于项目根目录的 `logs/` 文件夹：

- `logs/auth-service.log` - 认证服务日志
- `logs/authz-service.log` - 授权服务日志
- `logs/gateway.log` - 网关服务日志
- `logs/security-audit.log` - 安全审计日志

## 故障排查

### 服务无法启动

1. **检查端口占用**
   ```bash
   # macOS/Linux
   lsof -i :8080  # Gateway
   lsof -i :8081  # Auth Service
   lsof -i :8082  # Authz Service
   ```

2. **检查外部服务连接**
   - 查看日志中是否有MySQL连接错误
   - 查看日志中是否有Redis连接错误
   - 查看日志中是否有Nacos注册错误

3. **检查依赖**
   ```bash
   # 清理并重新构建
   mvn clean install -DskipTests
   ```

### Gateway返回401错误

1. 检查请求路径是否在白名单中
2. 检查JWT令牌是否有效
3. 检查Redis中是否存储了令牌
4. 查看 `logs/gateway.log` 和 `logs/security-audit.log`

### 数据库相关错误

1. 确保数据库表已创建
2. 检查数据库连接配置
3. 查看MyBatis SQL日志（已启用 `StdOutImpl`）

## 开发建议

### IDE配置
- 推荐使用IntelliJ IDEA
- 安装Lombok插件
- 启用注解处理器（Annotation Processing）

### 调试模式
在IDE中以调试模式运行服务，可以设置断点进行调试。

### 热重载
使用Spring Boot DevTools可以实现代码热重载：
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <optional>true</optional>
</dependency>
```

## 生产环境部署

生产环境建议：
1. 使用Docker容器化部署
2. 使用Kubernetes进行编排
3. 配置外部配置中心（如Nacos Config）
4. 使用专业的日志收集系统（如ELK）
5. 配置监控和告警（如Prometheus + Grafana）
6. 使用HTTPS协议
7. 定期备份数据库和Redis数据
