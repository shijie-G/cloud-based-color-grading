# Gateway 模块说明

## 模块概述

**模块名称：** gateway（API网关）  
**端口：** 8080  
**职责：** 统一入口、认证授权拦截、路由转发

API网关是系统的统一入口，负责请求路由、JWT令牌验证、权限检查、请求转发等功能。

## 核心功能

### 1. 请求路由

#### 路由配置
```yaml
spring:
  cloud:
    gateway:
      routes:
        # 认证服务路由
        - id: auth-service
          uri: http://localhost:8081
          predicates:
            - Path=/auth/**
        
        # 授权服务路由
        - id: authz-service
          uri: http://localhost:8082
          predicates:
            - Path=/roles/**,/permissions/**,/menus/**
        
        # 用户管理路由
        - id: user-service
          uri: http://localhost:8081
          predicates:
            - Path=/users/**
```

### 2. 认证过滤器（JwtAuthenticationFilter）

**职责：** JWT令牌验证

**执行顺序：** -100（优先级高）

**处理流程：**
```
1. 检查请求路径是否在白名单中
   ├─ 是 → 直接放行
   └─ 否 → 继续验证
2. 提取Authorization头中的JWT令牌
   ├─ 不存在 → 返回401
   └─ 存在 → 继续验证
3. 验证JWT令牌签名和过期时间
   ├─ 无效 → 返回401
   └─ 有效 → 继续验证
4. 从令牌中提取用户ID
5. 查询Redis验证令牌是否存在
   ├─ 不存在 → 返回401（可能已登出）
   └─ 存在 → 继续
6. 检查令牌是否需要刷新（剩余时间<30分钟）
   ├─ 需要 → 生成新令牌，更新Redis，添加到响应头
   └─ 不需要 → 继续
7. 将用户信息添加到请求头
   - X-User-Id: 用户ID
   - X-User-Name: 用户名
   - X-User-Roles: 角色列表
8. 继续过滤器链
```

**白名单配置：**
```yaml
gateway:
  whitelist:
    - /auth/login
    - /auth/register
    - /actuator/**
    - /favicon.ico
```

### 3. 权限过滤器（PermissionAuthorizationFilter）

**职责：** 权限检查

**执行顺序：** -90（在认证过滤器之后）

**处理流程：**
```
1. 从请求头提取用户ID
   ├─ 不存在 → 返回401
   └─ 存在 → 继续
2. 获取请求路径和HTTP方法
3. 调用授权服务检查权限
   ├─ 无权限 → 返回403
   └─ 有权限 → 继续
4. 继续过滤器链
```

## 服务客户端

### PermissionClient

**职责：** 调用授权服务检查权限

**类路径：** `cn.gsjgsj.gateway.client.PermissionClient`

**主要方法：**
```java
// 检查用户权限
boolean hasPermission(Long userId, String resourcePath, String method)
```

**实现方式：**
```java
@Component
public class PermissionClient {
    
    @Autowired
    private WebClient webClient;
    
    @Value("${authz-service.url}")
    private String authzServiceUrl;
    
    public boolean hasPermission(Long userId, String resourcePath, String method) {
        try {
            Boolean result = webClient.get()
                .uri(authzServiceUrl + "/permissions/check")
                .header("X-User-Id", userId.toString())
                .header("X-Resource-Path", resourcePath)
                .header("X-Method", method)
                .retrieve()
                .bodyToMono(Boolean.class)
                .block();
            
            return result != null && result;
        } catch (Exception e) {
            // 调用失败，默认拒绝访问
            return false;
        }
    }
}
```

## 配置说明

### application.yml

```yaml
spring:
  application:
    name: gateway
  cloud:
    gateway:
      routes:
        # 认证服务路由
        - id: auth-service
          uri: ${AUTH_SERVICE_URL:http://localhost:8081}
          predicates:
            - Path=/auth/**
          filters:
            - StripPrefix=0
        
        # 授权服务路由
        - id: authz-service
          uri: ${AUTHZ_SERVICE_URL:http://localhost:8082}
          predicates:
            - Path=/roles/**,/permissions/**,/menus/**
          filters:
            - StripPrefix=0
        
        # 用户管理路由
        - id: user-service
          uri: ${AUTH_SERVICE_URL:http://localhost:8081}
          predicates:
            - Path=/users/**
          filters:
            - StripPrefix=0
      
      # 全局CORS配置
      globalcors:
        cors-configurations:
          '[/**]':
            allowedOrigins: "*"
            allowedMethods:
              - GET
              - POST
              - PUT
              - DELETE
              - OPTIONS
            allowedHeaders: "*"
            allowCredentials: false
            maxAge: 3600
  
  data:
    redis:
      host: ${REDIS_HOST:localhost}
      port: ${REDIS_PORT:6379}
      password: ${REDIS_PASSWORD:}

server:
  port: 8080

# JWT配置
jwt:
  secret: ${JWT_SECRET:your-secret-key}
  validity-in-milliseconds: ${JWT_VALIDITY:7200000}  # 2小时
  refresh-threshold: ${JWT_REFRESH_THRESHOLD:1800000}  # 30分钟

# 网关配置
gateway:
  whitelist:
    - /auth/login
    - /auth/register
    - /actuator/**
    - /favicon.ico

# 授权服务配置
authz-service:
  url: ${AUTHZ_SERVICE_URL:http://localhost:8082}

# 安全配置
security:
  audit:
    enabled: ${SECURITY_AUDIT_ENABLED:true}
```

## 请求流程

### 完整请求流程

```
客户端
  ↓
1. 发送请求到网关（http://gateway:8080/users）
  ↓
2. 网关接收请求
  ↓
3. JwtAuthenticationFilter（认证过滤器）
  ├─ 检查白名单
  ├─ 验证JWT令牌
  ├─ 查询Redis
  ├─ 检查是否需要刷新
  └─ 添加用户信息到请求头
  ↓
4. PermissionAuthorizationFilter（权限过滤器）
  ├─ 提取用户ID
  ├─ 调用授权服务检查权限
  └─ 有权限则继续，无权限返回403
  ↓
5. 路由转发
  └─ 根据路由配置转发到后端服务
  ↓
6. 后端服务处理请求
  └─ 从请求头获取用户信息
  ↓
7. 返回响应
  ↓
8. 网关返回响应给客户端
```

### 请求头传递

**网关添加的请求头：**
```

X-User-Name: testuser
```

```java
    @RequestHeader("X-User-Roles") String roles

}
```

## 错误处理

### 401 未授权

**触发条件：**
- 缺少Authorization头
- JWT令牌无效
- JWT令牌过期
- Redis中不存在令牌（已登出）

**响应：**
```json
{
  "code": 401,
  "message": "未授权，请先登录",
  "data": null
}
```

### 403 禁止访问

**触发条件：**
- 用户无权限访问资源

**响应：**
```json
{
  "code": 403,
  "message": "无权限访问该资源",
  "data": null
}
```

### 504 网关超时

**触发条件：**
- 后端服务响应超时

**响应：**
```json
{
  "code": 504,
  "message": "网关超时",
  "data": null
}
```

## 安全机制

### 1. JWT令牌验证
- 验证签名
- 验证过期时间
- 验证Redis中是否存在

### 2. 白名单机制
- 登录接口跳过认证
- 公开接口跳过认证

### 3. 权限检查
- 每个请求都检查权限
- 无权限直接拒绝

### 4. 令牌刷新
- 剩余时间<30分钟自动刷新
- 新令牌添加到响应头

## 常见问题

### Q1: 如何添加新的路由？
**A:** 在 `application.yml` 的 `spring.cloud.gateway.routes` 中添加新路由配置。

### Q2: 如何添加白名单路径？
**A:** 在 `application.yml` 的 `gateway.whitelist` 中添加路径。

### Q3: 令牌刷新后，客户端如何获取新令牌？
**A:** 新令牌会添加到响应头 `X-New-Token` 中，客户端需要读取并更新本地令牌。

### Q4: 如何禁用权限检查？
**A:** 移除 `PermissionAuthorizationFilter` 或在配置中禁用。

### Q5: 如何查看网关日志？
**A:** 查看 `logs/gateway.log` 文件或使用日志聚合工具。
