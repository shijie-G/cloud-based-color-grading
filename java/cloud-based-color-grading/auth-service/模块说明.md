# Auth Service 模块说明

## 模块概述

**模块名称：** auth-service（认证服务）  
**端口：** 8081  
**职责：** 用户认证、令牌管理、用户管理

认证服务是用户认证授权系统的核心模块之一，负责处理用户登录、登出、JWT令牌生成和验证、用户账户管理等功能。

## 核心功能

### 1. 用户认证

#### 1.1 用户登录
- **接口：** `POST /auth/login`
- **功能：** 验证用户凭证，生成JWT令牌
- **流程：**
  1. 验证用户名和密码
  2. 检查账户状态（是否禁用、是否锁定）
  3. 生成JWT令牌
  4. 将令牌存储到Redis
  5. 查询用户菜单和权限
  6. 返回登录响应

#### 1.2 用户登出
- **接口：** `POST /auth/logout`
- **功能：** 使用户令牌失效
- **流程：**
  1. 从请求头获取用户ID
  2. 从Redis删除用户令牌
  3. 返回成功响应

#### 1.3 令牌刷新
- **接口：** `POST /auth/refresh`
- **功能：** 刷新即将过期的令牌
- **流程：**
  1. 验证旧令牌有效性
  2. 生成新令牌
  3. 更新Redis中的令牌
  4. 返回新令牌

### 2. 用户管理

#### 2.1 创建用户
- **接口：** `POST /users`
- **功能：** 创建新用户账户
- **验证：**
  - 用户名唯一性
  - 密码强度（可选）
  - 必填字段验证

#### 2.2 查询用户列表
- **接口：** `GET /users`
- **功能：** 分页查询用户列表
- **参数：**
  - `current`: 当前页码（默认1）
  - `size`: 每页大小（默认10）
  - `username`: 用户名筛选（可选）

#### 2.3 更新用户信息
- **接口：** `PUT /users/{id}`
- **功能：** 更新用户信息
- **支持更新：**
  - 昵称
  - 邮箱
  - 手机号
  - 密码（加密存储）

#### 2.4 禁用用户
- **接口：** `DELETE /users/{id}`
- **功能：** 禁用用户账户
- **副作用：**
  - 使该用户所有令牌失效
  - 清除权限缓存

#### 2.5 重置密码
- **接口：** `POST /users/{id}/reset-password`
- **功能：** 重置用户密码
- **流程：**
  1. 生成8位随机临时密码
  2. 加密并更新密码
  3. 使所有令牌失效
  4. 返回临时密码

### 3. 安全防护

#### 3.1 登录失败计数
- **功能：** 记录登录失败次数
- **机制：**
  - 使用Redis存储失败次数
  - Key: `login:fail:{username}`
  - 过期时间：15分钟

#### 3.2 账户锁定
- **触发条件：** 连续5次登录失败
- **锁定时长：** 15分钟
- **机制：**
  - Redis标记：`account:locked:{username}`
  - 锁定期间拒绝登录

#### 3.3 密码加密
- **算法：** BCrypt
- **特点：**
  - 自动加盐
  - 每次加密结果不同
  - 单向加密，不可逆

## 核心类说明

### Controller层

#### AuthController
**职责：** 处理认证相关的HTTP请求

**主要方法：**
- `login(LoginRequest)`: 处理登录请求
- `logout(Long userId)`: 处理登出请求
- `refreshToken(String authorization)`: 处理令牌刷新请求

#### UserController
**职责：** 处理用户管理相关的HTTP请求

**主要方法：**
- `createUser(User)`: 创建用户
- `getUserList(Long current, Long size, String username)`: 查询用户列表
- `updateUser(Long id, User)`: 更新用户信息
- `disableUser(Long id)`: 禁用用户
- `resetPassword(Long id)`: 重置密码

### Service层

#### AuthService
**职责：** 认证业务逻辑

**主要方法：**
```java
// 用户登录
LoginResponse login(String username, String password)

// 用户登出
void logout(Long userId)

// 刷新令牌
String refreshToken(String oldToken)

// 验证令牌
boolean validateToken(String token)

// 记录登录失败
boolean recordLoginFailure(String username)

// 检查账户是否被锁定
boolean isAccountLocked(String username)
```

#### UserService
**职责：** 用户管理业务逻辑

**主要方法：**
```java
// 根据用户名查询用户
User getUserByUsername(String username)

// 根据用户ID查询用户
User getUserById(Long userId)

// 创建用户
boolean createUser(User user)

// 更新用户信息
boolean updateUser(User user)

// 检查用户名是否已存在
boolean isUsernameExists(String username)

// 分页查询用户列表
Page<User> getUserList(Page<User> page, String username)

// 禁用用户
boolean disableUser(Long userId)

// 启用用户
boolean enableUser(Long userId)

// 更新用户最后登录时间
void updateLastLoginTime(Long userId)
```

### Mapper层

#### UserMapper
**职责：** 用户数据访问

**继承：** `BaseMapper<User>`（MyBatis-Plus）

**自动提供的方法：**
- `insert(User)`: 插入用户
- `selectById(Long)`: 根据ID查询
- `updateById(User)`: 根据ID更新
- `deleteById(Long)`: 根据ID删除
- `selectPage(Page, Wrapper)`: 分页查询

## 配置说明

### application.yml

```yaml
spring:
  application:
    name: auth-service
  datasource:
    url: jdbc:mysql://host:port/database
    username: root
    password: password
  data:
    redis:
      host: localhost
      port: 6379
      password: password

server:
  port: 8081

# JWT配置
jwt:
  secret: your-secret-key
  expiration: 7200000  # 2小时
  refresh-threshold: 1800000  # 30分钟

# 安全配置
security:
  login:
    max-failures: 5  # 最大失败次数
    lock-duration: 900  # 锁定时长（秒）
  password:
    encoder: bcrypt  # 密码加密算法
```

## 安全机制

### 1. 密码安全
- **加密算法：** BCrypt
- **加盐：** 自动加盐
- **强度：** 10轮（默认）

### 2. 令牌安全
- **算法：** HS256（HMAC-SHA256）
- **过期时间：** 2小时
- **刷新机制：** 剩余时间<30分钟时自动刷新

### 3. 防暴力破解
- **失败限制：** 5次
- **锁定时长：** 15分钟
- **自动解锁：** 15分钟后自动解锁

### 4. 会话管理
- **单点登录：** 同一用户只能有一个有效令牌
- **强制登出：** 修改密码后所有令牌失效

## 常见问题

### Q1: 忘记密码怎么办？
**A:** 使用重置密码接口 `POST /users/{id}/reset-password`，会生成临时密码。

### Q2: 如何修改令牌过期时间？
**A:** 修改 `application.yml` 中的 `jwt.expiration` 配置。

### Q3: 如何修改登录失败限制？
**A:** 修改 `application.yml` 中的 `security.login.max-failures` 配置。

### Q4: 令牌存储在哪里？
**A:** 令牌存储在Redis中，Key为 `token:{userId}`。

### Q5: 如何强制用户下线？
**A:** 从Redis删除用户令牌：`DEL token:{userId}`。
